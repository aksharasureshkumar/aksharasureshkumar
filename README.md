# Hi, I'm Akshara 👋

I'm a Bioinformatics master's student at Northeastern University with a background
in biomedical sciences. I'm interested in building reliable data tools that turn
genomic and proteomic data into insights for drug target discovery.

### 📂 Projects
- **[Woolly mammoth aDNA reproducibility](https://github.com/aksharasureshkumar/mammoth-adna-reproducibility)**:
  reproduced the ancient DNA alignment workflow from a 2026 *Cell* study using the
  Snakemake-based GenErode pipeline on an HPC cluster
- **[Migraine lead molecule identification](https://github.com/aksharasureshkumar/migraine-lead-molecule-identification)**:
  in silico drug discovery for migraine-associated proteins (CACNA1A, SCN1A, ATP1A2)
  using STRING, PyRx docking, SwissADME, and ProTox
